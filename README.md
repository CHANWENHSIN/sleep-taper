# 睡眠決策中心

這是一個簡易的睡眠紀錄與安眠藥劑量觀察工具，使用純 HTML、CSS、JavaScript 製作，可直接在瀏覽器開啟使用。

資料會儲存在瀏覽器的 `localStorage`，不需要後端資料庫。

---

## 功能說明

### 1. 每日睡眠紀錄

可記錄以下資料：

- 記錄日期
- 劑量
  - 0.5
  - 0.375
  - 0.25
  - 0.125
  - 0
- 入睡時間（分鐘）
- 半夜醒來次數
  - 0 次
  - 1 次
  - 2 次以上
- 起床精神分數（1～5）
- 是否有吃彰蜆活力
- 咖啡時間
  - 無
  - 早上
  - 下午
  - 晚上
- 週期狀態
  - 平常
  - 生理期前
  - 生理期中
  - 生理期後

---

## 決策邏輯說明

本工具的決策建議不是醫療診斷，也不是自動降藥指令。

目前邏輯是用來判斷：

> 在目前劑量下，睡眠是否穩定到可以與醫師討論下一階段調整。

也就是說，系統判斷的是「目前劑量下的穩定度」，不是判斷自然睡眠能力已完全恢復。

---

## 睡眠穩定條件

目前判定「穩定」的基本條件為：

```text
入睡時間 ≤ 30 分鐘
半夜醒來 ≤ 1 次
起床精神 ≥ 3
```

因此，半夜醒來 1 次不會直接被判定為睡不好。

但如果半夜醒來後很久睡不回去，目前版本尚未記錄此欄位，未來可考慮新增「醒後再入睡時間」。

---

## 睡眠品質分級

系統內部將單日睡眠分為四級：

### A 級：很好

```text
入睡時間 ≤ 15 分鐘
半夜醒來 ≤ 1 次
起床精神 ≥ 4
```

### B 級：穩定

```text
入睡時間 ≤ 30 分鐘
半夜醒來 ≤ 1 次
起床精神 ≥ 3
```

### C 級：普通

```text
入睡時間 ≤ 45 分鐘
半夜醒來 ≤ 2 次
起床精神 ≥ 2
```

### D 級：不穩

不符合以上條件時，視為不穩定。

---

## 強制保守條件

若最近紀錄出現以下任一狀況，系統會優先給出保守建議：

```text
入睡時間 > 45 分鐘
半夜醒來 2 次以上
起床精神 ≤ 1
最近兩天連續睡眠變差
```

目前欄位的「半夜醒來」只有：

```text
0 次
1 次
2 次以上
```

因此系統無法區分 2 次與 3 次以上。只要選到「2 次以上」，系統會先採取保守判斷。

---

## 干擾因子邏輯

干擾因子不再直接阻擋調整建議，而是改為扣分制。

系統會參考最近紀錄中的以下因素：

- 下午咖啡
- 晚上咖啡
- 彰蜆活力
- 生理期前
- 生理期中

早上咖啡不扣分。

干擾因子最多只扣到 2 分，避免因為生活中正常波動，導致系統永遠無法進入穩定評估。

---

## 同劑量觀察邏輯

系統會抓取最近「連續同劑量」的紀錄。

若同劑量紀錄不足 5 天，會顯示：

```text
同劑量不足
```

原因是劑量調整後，單日睡眠表現不一定穩定，至少需要累積數天資料才比較有參考價值。

---

## 決策分數概念

系統會根據以下項目形成決策分數：

1. 最新一天的睡眠品質分數
2. 最近同劑量期間的穩定天數
3. 是否有連續穩定紀錄
4. 干擾因子扣分
5. 是否觸發強制保守條件

簡化理解如下：

```text
睡眠品質分數 + 穩定加分 - 干擾扣分 = 決策參考分數
```

但只要觸發強制保守條件，系統會優先顯示保守建議，不會進入下一階段評估。

---

## 決策建議類型

目前系統會產生三種主要建議。

### 🟢 可與醫師討論下一階段

代表目前劑量下睡眠相對穩定。

顯示文字類似：

```text
目前劑量下睡眠穩定
可與醫師討論是否進入下一階段：0.375 → 0.25
```

注意：這不代表可以自行降藥，而是代表具備「與醫師討論」的條件。

---

### 🟡 建議維持觀察

代表睡眠大致尚可，但仍有波動或干擾因子。

顯示文字類似：

```text
睡眠大致穩定，但仍建議保守觀察
目前建議：維持目前劑量，再觀察 3～7 天
```

---

### 🔴 暫不建議調整

代表近期睡眠品質不穩。

顯示文字類似：

```text
近期睡眠不穩，暫不建議調整劑量
目前建議：維持目前劑量並觀察
```

## 歷史紀錄

所有紀錄會依日期排序，並顯示在「歷史紀錄」區塊。

每筆紀錄會顯示：

```text
日期｜劑量｜入睡時間｜夜醒次數｜精神分數｜彰蜆｜咖啡｜週期狀態
```

每筆紀錄旁邊都有刪除按鈕。

## 分析結果

目前分析區塊會統計：

- 生理期前紀錄筆數
- 平常紀錄筆數

此區塊主要是預留給未來分析週期狀態對睡眠的影響。

## 資料儲存方式

資料儲存在瀏覽器的 `localStorage`：

```javascript
const STORAGE_KEY = "sleepLogs";
```

資料不會上傳雲端，也不會同步到其他裝置。

若清除瀏覽器資料，紀錄可能會被刪除。

---

每筆紀錄格式如下：

## 使用方式

### 方式一：直接開啟 HTML

1. 將 HTML 檔案存成 `index.html`
2. 用 Chrome、Edge 或 Safari 開啟
3. 每天輸入睡眠資料
4. 系統會自動儲存在目前瀏覽器中

### 方式二：放到 CodePen

1. 將 HTML、CSS、JavaScript 貼到 CodePen
2. 儲存成一個 Pen
3. 手機或電腦都可以開啟
4. 注意：不同瀏覽器或不同裝置的 `localStorage` 不會自動同步

---

## 注意事項

本工具僅供個人紀錄與趨勢觀察使用。

安眠藥、鎮靜安眠藥、抗焦慮藥或其他助眠藥物的調整，應由醫師評估後進行。

請勿單純依照本工具結果自行停藥、減藥或加藥。

若出現以下狀況，應優先與醫師討論：

- 睡眠突然明顯惡化
- 連續多天夜醒增加
- 明顯焦慮、心悸、恐慌
- 白天精神嚴重變差
- 自行加藥後才睡得著
- 停藥或減藥後出現明顯反彈性失眠

---

## 目前限制

目前版本尚未記錄以下資訊：

- 醒後再入睡時間
- 總睡眠時數
- 實際上床時間
- 實際起床時間
- 醒來後是否焦慮
- 是否午睡
- 是否喝酒
- 是否運動
- 是否有重大壓力事件

因此目前決策邏輯只能根據既有欄位做初步判斷。
