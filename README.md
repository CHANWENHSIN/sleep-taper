# sleep-taper（睡眠減藥紀錄工具）

一個簡單的網頁工具，用來幫助記錄睡眠狀況，並輔助逐步減少安眠藥使用。

---

## 🧠 設計目的

在減少安眠藥的過程中，常會遇到以下問題：

- 不確定現在狀態能不能降藥
- 睡不好時容易懷疑自己、或亂調劑量
- 無法客觀判斷趨勢（是變好還是變差）

這個工具的目標是：

👉 **用簡單紀錄 + 明確規則，幫助做出穩定決策**

---

## ✨ 功能特色

- 📱 單頁網頁，打開即可使用（支援手機）
- 💾 使用 localStorage，本地儲存資料（不需登入）
- 📊 紀錄每日睡眠狀況：
  - 劑量
  - 入睡時間
  - 半夜醒來次數
  - 起床精神
- 🧭 自動判斷狀態：
  - 🟢 可以降藥
  - 🟡 維持劑量
  - 🔴 不穩定

---

## ⚙️ 判斷邏輯（簡化版）

系統會依據最近兩天的紀錄：

- 入睡 ≤ 20 分鐘  
- 半夜醒 ≤ 1 次  
- 精神 ≥ 3  

👉 若皆符合 → 顯示「可以降藥」

---

## 🚀 使用方式

1. 每天填寫當日狀況
2. 查看系統判斷結果
3. 依照結果決定是否調整劑量

---

## ⚠️ 注意事項

- 本工具僅作為輔助紀錄與參考，不構成醫療建議
- 減藥過程建議循序漸進，避免過快調整
- 若出現明顯不適，應暫停減量或尋求專業協助
